MY YANGA / EXISTING MEMBER

SET UP YOUR
ACCOUNT.

This is for supporters who already have an official membership number. It does not create a new membership, issue another number or require another payment to access MY YANGA.

SECURE SETUP
  1. 01Membership number
  2. 02Ownership verification
  3. 03Create password

Ownership is verified through an OTP sent only to the contact held in an authorized Yanga membership record, or through authorized staff verification.

STEP 01 / OFFICIAL MEMBERSHIP NUMBER

Enter your official membership number.

Use the number issued by Yanga or an authorized registration channel. An application reference from this website is not an official membership number.

STEP 02 / OWNERSHIP VERIFICATION

Confirm that the membership record is yours.

OTP VERIFICATION AVAILABLE

We will send a one-time code to the contact held in the authorized membership record.

AUTHORIZED STAFF FALLBACK

If you cannot access the official contact record, authorized staff can verify ownership manually. No account is activated until the official record is checked.

STEP 03 / CREATE PASSWORD

Create your MY YANGA password.

Your ownership has been verified against the authorized membership record. Create a password for future Member Login access.
